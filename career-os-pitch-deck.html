AI Architecture

Eight Claude integrations — all isolated, all purposeful.

Every AI call lives in src/lib/ai/ — never inline in a route handler. Prompt caching on all static system prompts cuts latency and cost by ~75%.

profile-extractor.ts

Resume / PDF / LinkedIn text → structured profile. Uses Claude's native document blocks. Extracts work history, education, and skills; normalises before inserting to vault.

path-navigator.ts

Streams 3 career paths as JSON. Fair Pay Engine salary anchors injected as authoritative ground truth so Claude never hallucinates MYR figures outside the cross-referenced bands.

coach.ts

Streaming coach with prompt-cached personality + dynamic profile context. Salary Engine block injected per call. Life Chapter context shapes every piece of advice naturally.

coach-memory.ts

Off-path memory summariser. After each session, Haiku compresses conversation turns into a running summary stored in Supabase — the coach builds a deepening understanding of the candidate across sessions.

persona-profiler.ts

MBTI-style + Big Five (OCEAN) + workplace behavioural profile. Evidence-grounded — no inference without supporting data. No protected characteristics (age, gender, ethnicity) ever inferred.

skill-insight.ts + career-synthesizer.ts + minutes.ts

Per-skill recruiter-grade insight citing your own work history. AI career identity narrative. Conversation minutes (summary + action items) for candidate interactions.

07 / 14
C-04 Fair Pay Engine

Salary truth from four independent sources.

A deterministic, LLM-free cross-reference engine. No hallucinated figures — only cross-validated market data with an explicit confidence signal.

JobStreet Malaysia

Volume source. Strong on junior and mid-level roles across broad market.

Robert Walters

Specialist + senior salary survey 2025. Weighted up at senior seniority tier.

Michael Page

Premium MNC-oriented guide 2025. Used for MNC contextual adjustments.

DOSM

National floor only (Labour Force Survey). Excluded from convergence; used as hard minimum.

Pairwise Convergence Algorithm

JS, RW, and MP midpoints are compared pairwise. A pair "converges" when midpoints sit within 10% of each other. Output: a market band, a convergence factor, and a spread penalty.

HIGH — ≥2 pairs within 10%, spread ≤20%
MEDIUM — partial agreement
VOLATILE — spread >25%, ≤1 pair agrees

Contextual Adjustments Applied

The engine adjusts dynamically based on context:

  • +MNC employer  +25%
  • +Premium skills (AWS, Kubernetes, TensorFlow…)  +12–20%
  • −Startup environment  −10%
  • −Penang / Johor Bahru  −15% vs KL baseline
  • ×Singapore  ×2.7 SGD conversion

Covers 11 roles × 3 seniority levels. REST endpoint at GET /api/candidate/salary-confidence. Embedded in Coach and Path Navigator — Claude uses engine figures as authoritative ground truth and cannot override them.

08 / 14
C-03 AI Career Coach

A coach that remembers you — session to session.

What makes it different

  • →Persistent sessions — every conversation saved to Supabase with a session sidebar. Switch between past sessions like tabs.
  • →Evolving memory — after each session, an off-path Haiku summariser compresses conversation turns into a running summary. Injected into every future call — the coach builds up knowledge of who you are over time.
  • →Knows your actual profile — skills, work history, salary aspirations, life context, and dream role are all in the dynamic context block.
  • →Fair Pay Engine embedded — salary questions get cross-referenced MYR ranges with a confidence signal, not a guess.
  • →Life Chapter aware — advice accounts for real constraints (career break, eldercare, study) without making them the focus.
  • →12 APAC languages — coach responds in the candidate's selected language; proper nouns, salary figures, and role titles stay in English.

Prompt Caching Architecture

The 1,000-word coaching personality prompt is marked cache_control: ephemeral — cached by Anthropic for up to 5 minutes. The dynamic profile context block is passed uncached per call. This gives ~75% latency and token-cost reduction on the cached portion.

Floating AI Orb

A persistent floating orb sits in the bottom-right corner of every candidate page. Opens a full-screen coaching panel without leaving the current page — the coach is never more than one click away, regardless of where the candidate is in the app.

MYR salary data throughout

12 APAC languages

English, Bahasa Melayu, Bahasa Indonesia, 中文(简体 + 繁體), 日本語, 한국어, ภาษาไทย, Tiếng Việt, Filipino, हिंदी, தமிழ். UI switches instantly; AI-generated content requested in the active language.

Malaysian policy-aware AI

Coach references HRDC-funded training, PERKESO/SOCSO reskilling grants, EPF considerations, and halal economy sectors when relevant. B40/M40 context built into advice framing.

TVET + diploma first

PDPA-aligned

Talentbank integration path
