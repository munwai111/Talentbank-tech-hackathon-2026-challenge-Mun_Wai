# PRD — C-04 Fair Pay Engine (Standalone Signal)
**Module:** Talentbank Challenge C-04  
**Status:** Partial (embedded in paths) → Upgrade to visible standalone signal  
**Effort estimate:** 2–4 hours  
**Dependencies:** Path Navigator (already has salary data), `/jobs` page, AI Coach

---

## Problem Statement

Talentbank's C-04 module asks: *"Are you paid what you're worth, or just what you accepted?"* Career OS embeds MYR salary ranges inside Path Navigator output, but there's no moment where a candidate can see their current salary vs. market in a clear, dedicated signal. Most Malaysian candidates — especially those early in their career — have no idea if they're underpaid. The data is already in the system; it just isn't surfaced as a standalone, actionable insight.

---

## Goals

1. C-04 module explicitly addressed in hackathon submission
2. Candidate sees a clear salary signal on their dashboard or job match view
3. AI Coach can answer "am I underpaid?" with specific MYR data
4. No new AI calls needed — data already generated by Path Navigator

---

## Non-Goals

- Employer-side salary benchmarking or compensation analytics — v2
- Salary negotiation scripts or letter generation — v2
- Real-time salary data feed from job boards — v2
- Storing candidate's current salary (privacy consideration) — v2

---

## User Stories

**As a candidate,** I want to see the market salary range for my current role, so that I know whether I should be asking for a raise.

**As a candidate browsing job matches,** I want to see the salary range for each role before I apply, so that I can filter for roles that match my needs.

**As a candidate who just generated career paths,** I want to understand where my current salary sits relative to each path's range, so that I can see the financial case for making a move.

---

## Requirements

### P0 — Must Have

**Salary range on job match cards**
- Each job card on `/jobs` shows `salary_min – salary_max MYR/month` if the employer has provided it (or a market estimate if not)
- If employer hasn't provided salary: show "Market range: RM X,XXX – RM X,XXX/month" derived from Path Navigator market data for that role title
- Label clearly: "Posted salary" vs "Market estimate"

**"Fair Pay" signal in Path Navigator**
- Under each career path, add: "Market salary for this move: RM X,XXX – RM X,XXX/month"
- This is already in the JSON — just needs to be visually prominent with a dedicated label and icon
- Add a one-line note: "Professionals in Malaysia with your skill set typically earn in this range"

**AI Coach can answer salary questions**
- Coach system prompt already includes APAC market context — verify it includes specific MYR ranges for common roles
- Add to coach system prompt: a salary reference table for common Malaysian tech roles at junior/mid/senior levels
- This enables: "Am I underpaid as a junior dev in KL?" → specific, grounded answer

### P1 — Nice to Have

- Dashboard widget: "Your estimated market value" — a range derived from the candidate's skill set and experience level, updated when they add skills
- "Salary gap" indicator: if candidate's profile suggests they're below market, show a yellow chip "You may be underpaid — ask your coach"

### P2 — Future

- Candidate inputs current salary (optional, private) → platform shows "you are X% below/above market"
- Employer-side: salary benchmarking against market for job posts
- Salary trend data: "This role's salary in KL grew 12% in the last 2 years"
